# ورشة المدار 🛰️

لعبة متصفح عربية: محاكي ورشة تصليح في مدينة فضائية. تستقبل الزبائن، تصلّح أغراضهم عبر ألعاب مصغّرة، تبني سمعتك، وتطوّر كشكك الصغير إلى ملجأ ثم برج من أدوار... حتى تركّب له محركاً وتطلقه سفينةً بين النجوم.

- **التقنية:** Vite + Phaser 3 + JavaScript (ES modules)، بدون خادم.
- **كل الرسومات** مولّدة بالكود (Phaser Graphics)، و**كل الأصوات** مولّدة بـ Web Audio API. لا توجد صور أو ملفات صوت خارجية.
- **الشاشة** عمودية 9:16 وتتكيّف مع الجوال والكمبيوتر، وتدعم اللمس والماوس.
- **الواجهة** عربية بالكامل من اليمين لليسار بخط Cairo.
- **الحفظ** تلقائي في `localStorage` بنهاية كل يوم وبعد كل عملية شراء.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير على http://localhost:5173
npm run build    # بناء نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
```

## طريقة اللعب

1. يدخل الزبون ويشرح مشكلته في حوار قصير (المس الشاشة للمتابعة).
2. يضع الغرض على الطاولة.
3. تختار: **قبول**، أو **فاوض** (يرفع السعر 30% إذا نجح، وقد يغضب الزبون ويمشي)، أو **رفض**.
4. تلعب لعبة مصغّرة لإصلاح الغرض. الدقة والسرعة تحدّدان الأجر والسمعة.
5. كل يوم فيه 5 إلى 7 زبائن، ثم ملخص اليوم ثم متجر التطويرات.

### الألعاب المصغّرة (`src/minigames/`)

| الملف | اللعبة |
|---|---|
| `LockGame.js` | فكّ القفل: رمز سري من 4 أرقام بتلميحات ملوّنة |
| `CleanGame.js` | التنظيف: امسح الصدأ والأوساخ بإصبعك حتى 100% |
| `ScrewsGame.js` | البراغي: فكّها بالترتيب الصحيح بحركة دائرية (الترتيب يختفي في الأيام المتقدمة) |
| `WiresGame.js` | الأسلاك: وصّل الألوان المتطابقة بدون تقاطع |
| `SwapGame.js` | تبديل القطعة: ارمِ المحترقة في السلة واسحب المطابقة من الدرج |
| `CalibrateGame.js` | معايرة الطاقة: أوقف المؤشر في المنطقة الخضراء 3 مرات |

الصعوبة ترتفع تدريجياً مع الأيام (خانات أكثر، شبكة أكبر، براغي أكثر، مناطق أضيق، وقت أقل).

### التطوير والتقدّم

1. **كشك صغير** (البداية)
2. **ملجأ**: تختار من 3 تصاميم (القبة الزجاجية، حاويات الشحن، الكهف الصخري)، ويتغيّر شكل الورشة.
3. **برج من أدوار**: دور الأدوات (وقت أطول)، دور الاستقبال الفاخر (زبائن أغنى)، دور المخزن (دخل يومي ويستبعد قطعاً خاطئة).
4. **المحرّك المداري**: يحتاج الأدوار الثلاثة، ويطلق الورشة سفينة فضاء = نهاية اللعبة بمشهد إطلاق متحرك.

العرض المقطعي للبرج يتحدّث بصرياً في الملخص والمتجر. وهناك تطويرات صغيرة: مفكّ كهربائي (3 مستويات)، عدسة فاحصة، دلّة قهوة، لوحة نيون.

### الخيارات الأخلاقية

بعض الزبائن يعرضون صفقات مشبوهة: جهاز مسروق، قطعة مهرّبة، رشوة لتخريب مولّد منافس، مفتّش يطلب رشوة، ولاجئ لا يملك ثمن الإصلاح.
قراراتك تؤثر على الفلوس والسمعة، وتفتح أحداثاً لاحقة: زيارة الرقيب صخر (ملثّم من أمن المحطة)، عودة المهرّب بعرض أكبر، عودة اللاجئ بهدية، أو ابتزاز متكرر من المفتّش. ولقبك في شاشة النهاية يعتمد على اختياراتك.

### نظام المسروقات واللصوص

من اليوم الثاني يجيك زبائن مريبون بأغراض محفور عليها اسم شخص ثاني:
- **لوحة البلاغات** (على الجدار يمين النافذة) فيها الأغراض المبلّغ عنها اليوم وأسماء ملّاكها. قارن الاسم المحفور قبل لا تقرّر، فبعض المريبين أبرياء والغرض فعلاً لهم.
- **اقبل المهمة:** أجر أعلى، لكن صاحب الغرض بيجيك بعد يومين يسأل عنه.
- **بلّغ الشرطة:** تشغّل اللص بالكلام وتختار ردودك على أسئلته قبل ما ينتهي الوقت، وفيه شريط لوصول الشرطة وشريط لشكّ اللص. إذا وصلت الشرطة قبل ما يشكّ، يُقبض عليه مع أضواء وصفّارة، وتاخذ مكافأة. وإذا شكّ وهرب، يترك المسروق وراه.
- **صاحب الغرض** يزورك بعدها يشكرك ويعطيك فلوساً وهدية تنحطّ على **رف الهدايا** وتعطيك ميزة دائمة: صقر ذهبي، وسام الأمانة، فانوس دافئ، بلّورة فضائية، وطائرة حراسة صغيرة تطير في ورشتك...
- البلاغ على بريء يخسّرك من سمعتك.
- **شريط «أخبار المدار»** أسفل النافذة ينقل أخبار السوق وبطولاتك.

### العمق: أحداث، عقود، مهارات، سلاسل

- **صباح كل يوم** شاشة فيها حدث اليوم (إن وجد) وعقدين يوميين.
- **الأحداث اليومية:** عاصفة شمسية (أجر المعايرة ×1.8)، مهرجان السوق (+2 زبائن و+20% أجر)، انقطاع كهرباء (دوام أقصر وأجر الأقفال ×1.7)، عاصفة غبار، وزخّة نيازك.
- **العقود اليومية:** مثل «أصلح 3 أقفال» أو «لا ترفض أي زبون» أو «اقبض على لص»، ومكافأتها فورية. تشوفها من لوحة «العقود» يسار النافذة.
- **المهارات:** كل نوع إصلاح له مستوى من 1 إلى 5 يرتفع بالخبرة، وكل مستوى يعطي +6% وقت و+5% أجر. تشوفها من زر «المهارات» في المتجر.
- **سلسلة الإتقان:** الإصلاحات الممتازة ورا بعض ترفع الأجر حتى +30%.

### الصوت

- **بدون موسيقى:** فيه مؤثرات صوتية بس.
- **الشخصيات تتكلم بلهجتنا الخليجية:** إذا كان في الجهاز صوت عربي رجالي (مثل Maged في آيفون أو Naayf في ويندوز)، الشخصيات تقرأ كلامها بنبرة طبيعية. وإذا ما فيه، تتكلم بـ«همهمة» مولّدة لكل شخصية نبرتها. ما تُستخدم أصوات نسائية أبداً.
- **الإعدادات:** تقدر تغيّر وضع الأصوات (تلقائي / همهمة / بدون).

### الشخصيات

كل الشخصيات رجال أو روبوتات أو كائنات فضائية، **بدون أي ملامح وجه**. مولّد الشخصيات (`src/gfx/CharacterGenerator.js`) يركّب:
- **غطاء الوجه:** شماغ وعقال مع ظل داكن مكان العين، خوذة فضاء بزجاج عاكس، قناع غاز بفلاتر، روبوت رأسه شاشة رموز، أو عباءة وقلنسوة فيها ظلام ونقطتا ضوء.
- **اللون + الملابس** (ثوب وبشت، جاكيت، درع، أفرول، عباءة، هيكل روبوت) **+ إكسسوار** (هوائي، شارة، سلسلة ذهب، وشاح، مصباح كتف، حقيبة ظهر).

التعابير تظهر بحركة الجسم (هزّ الرأس، إيماءة، طرق الطاولة، اهتزاز غضب، قفزة فرح) وفقاعات رموز فوق الرأس (؟ ! … ★ ♪ ◈ ✓ ✗). ويدا اللاعب بالقفازات تظهران أسفل الشاشة.

## هيكل المشروع

```
src/
  main.js              نقطة البداية وإعداد Phaser
  state.js             حالة اللعبة والحفظ وتأثيرات التطويرات
  audio.js             المؤثرات الصوتية (Web Audio)
  data/
    customers.json     الزبائن (قصة، متكررون، عامّون) والحوارات وردود الفعل
    upgrades.json      التطويرات وتصاميم الملجأ
  systems/customers.js بناء طابور الزبائن اليومي والذاكرة
  scenes/              القائمة، الورشة، اللعبة المصغّرة، الملخص، المتجر، الإعدادات، النهاية
  minigames/           الألعاب المصغّرة الست
  gfx/                 مولّد الشخصيات، الأغراض، المدينة، داخل الورشة، اليدان، البرج
  ui/                  الثيم، الأزرار، الشريط العلوي، صندوق الحوار، النوافذ المنبثقة
```

لإضافة زبون جديد: أضفه في `src/data/customers.json` (اسم، مظهر `look`، غرض `item`، حوار `dialog`، ولعبة `minigame`، واختيارياً `moral` للخيارات الأخلاقية).

## الرفع على Render (Static Site)

المشروع فيه ملف `render.yaml` جاهز. أو يدوياً من لوحة Render:

1. **New → Static Site** واربطه بمستودع GitHub.
2. **Build Command:** `npm install && npm run build`
3. **Publish Directory:** `dist`
